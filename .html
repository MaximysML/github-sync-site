Быстрый старт

Начните за три шага

Для входа используется GitHub Personal Access Token вместо пароля.

Создайте токен

Откройте github.com/settings/tokens и создайте classic token. Для приватных репозиториев нужен доступ repo.

Настройте ПК

Установите программу, добавьте аккаунт, выберите репозиторий и папку, затем нажмите «Запустить».

Подключите телефон

На ПК выберите «Телефон → Включить доступ». В Android-приложении введите показанные HTTPS-адрес и код.

Частые вопросы

Нужно ли устанавливать Python или .NET?

Нет. Всё необходимое уже включено в Windows-установщик. Для Android нужна только система Android 6.0 или новее.

Почему адрес trycloudflare.com не открывается как сайт?

Это не обычный сайт, а адрес управления для Android-приложения. В браузере он может показывать ошибку или 404. Введите его вместе с кодом именно в GitHub Sync Remote.

Может ли телефон включить выключенный ПК?

Нет. ПК, программа GitHub Sync и интернет должны оставаться включёнными. Телефон управляет только процессом синхронизации.

Что делать, если локально удалённые файлы скачиваются снова?

Обычная синхронизация не восстанавливает их автоматически. Кнопка Reset нужна именно для восстановления файлов, которые вы удалили на ПК.

Где получить токен?

На странице GitHub Tokens. Не передавайте токен, адрес удалённого доступа и код другим людям.
